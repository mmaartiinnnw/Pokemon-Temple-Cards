# Proyecto Cartas Pokémon TCG Interactivas

Este es un proyecto front-end puro (HTML, CSS y JavaScript) que recrea las cartas de los tres starters clásicos de Kanto (Charizard, Blastoise y Venusaur) con un estilo TCG moderno y profesional.

El proyecto se enfoca en la fidelidad visual, las animaciones CSS avanzadas y la interactividad "bakana" con JavaScript para crear un efecto 3D Parallax y holográfico.

## ✨ Características Principales

Este proyecto no es solo una maqueta estática, incluye:

* **Tres Cartas Completas:** Charizard (Fuego), Blastoise (Agua) y Venusaur (Hierba), cada una con su propio esquema de color.
* **Fondo "Guapo":** Un fondo oscuro y animado con un patrón sutil de Pokéball y un halo de luz que sigue el movimiento del ratón por la página.
* **Diseño TCG Fiel:** El layout de las cartas (PS, ataques, debilidades, etc.) está estructurado para imitar una carta física moderna.
* **Efecto 3D Parallax (El script "Bakano"):** Al pasar el ratón, las cartas rotan sutilmente en 3D para dar una sensación de profundidad.
* **Borde Azul "Gaming":** Un borde exterior azul brillante alrededor de cada carta, en lugar del típico borde negro.
* **Efecto Neón Animado:** La ilustración del Pokémon tiene un borde de neón que brilla constantemente con el color de su tipo (Naranja, Azul, Verde).
* **Brillo Holográfico:** Una capa de brillo reflectante sigue al ratón *dentro* de la carta, dándole un acabado profesional.
* **Hover con Zoom:** Al pasar el ratón, la carta se hace más grande y se eleva para destacarla.
* **Imágenes 100% Funcionales:** Todos los iconos de energía y las ilustraciones se cargan desde CDNs estables (PokeAPI y PokemonTCG.io) para evitar enlaces rotos.
* **Enlaces Interactivos:** La ilustración de cada Pokémon es un enlace clicable a su respectiva página de Bulbapedia.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Para la estructura semántica de las cartas.
* **CSS3:** Para todo el diseño, animaciones (`@keyframes`), Flexbox, Grid, variables CSS (Custom Properties) y el efecto Neón.
* **JavaScript (ES6+):** Para controlar el efecto Parallax 3D y el seguimiento del ratón para los brillos holográficos.
